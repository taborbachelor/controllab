ControlLab Automated commissioning tests for industrial control logic, against a simulated line Source on GitHub

What you're looking at: a recording of one automated commissioning test. On the left, a simulated bulk-material line (bin → gate → feeder → conveyor → hopper) run by its control program, which sees only I/O, exactly as a PLC would. On the right, the test: it operates the line, injects the fault, and checks the controller's response stage by stage, each against a time limit. The playback is the run's own recorded telemetry, not an animation.
